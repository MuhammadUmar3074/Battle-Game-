Battle Game

HT Battle Game is a simple grid-based ship battle game where players try to find randomly placed hidden ships on a game board.

About the Game

In this game, the programmer randomly places ships on the game board, while the user can customize the board size by entering the number of rows and columns.

The objective is to guess the locations of hidden ships and hit them through strategic selections.
Features
 Random placement of ships on the game board.
 Customizable board size using rows and columns.
 Interactive gameplay based on user input.
 Randomized game setup for different experiences.
 Improves logical thinking and problem-solving skills.
 
How to Play:
Run the game.
Enter the desired number of rows.
Enter the desired number of columns.
The game randomly places ships on the board.
Enter your guesses to find the hidden ships.
Try to hit the ships and enjoy the game!
